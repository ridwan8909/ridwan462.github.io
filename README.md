# Portfolio Muhammad Ridwan

Laman peribadi ringkas. Tiada framework, cuma HTML dan CSS.

## Isi folder

    portfolio/
    |- index.html   <- halaman utama (isi kandungan)
    |- style.css    <- semua rupa: warna, font, jarak
    |- images/      <- semua gambar
    |- README.md    <- nota ni

## Cara tengok di komputer

Klik kanan index.html -> Open with -> Chrome.

## Cara ubah warna

Buka style.css, bahagian paling atas ada blok :root { }.
Tukar kod warna di situ, seluruh laman ikut.

## Cara masuk gambar

1. Letak gambar dalam folder images/
2. Dalam index.html, tulis:
   <img src="images/nama-gambar.jpg" alt="Penerangan gambar">

## Cara letak online (GitHub Pages)

1. Buat repository baru di github.com
2. Upload SEMUA isi folder ni (bukan folder ni sendiri)
3. Settings -> Pages -> Branch: main -> Save
